# WASMBOX

WASMBOX is a simplified project for executing small Python code snippets through a FastAPI backend and a WebAssembly-based execution layer.

## Planned Flow

User enters Python code
→ FastAPI Backend
→ WASM Execution Layer
→ Execute Code
→ Capture Output
→ Return Result
→ Display Output in UI

## Project Structure

- `backend/` - Backend and API code
- `frontend/` - User interface
- `wasm/` - WebAssembly execution layer
- `tests/` - Tests
